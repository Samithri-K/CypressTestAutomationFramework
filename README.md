## Cypress POM Test Automation Framework

A Cypress-based test automation framework using Page Object Model (POM) for scalable and maintainable web UI testing.

### Tech Stack
- Cypress
- JavaScript
- Mocha
- npm

### Features
- Page Object Model structure
- Reusable page classes
- Fixture-based test data
- Ready for CI/CD integration

### Run Tests
```bash
npm install
npm run cy:open
npm run cy:run
